# 🛡️ LinkGuard v2.0 - Защита от фишинга с toast-уведомлениями

LinkGuard — простая программа, которая защищает от фишинговых сайтов. Работает в фоновом режиме и показывает уведомления в стиле toast (справа внизу экрана).

## ✨ Основные возможности

- **Автоматическая проверка:** Копируйте ссылку — программа сама её проверит.
- **Защита от подделок:** Распознает фишинговые сайты с опечатками (например, `gooogle.com` вместо `google.com`).
- **Проверка возраста:** Предупреждает, если сайту меньше 30 дней.
- **Большой белый список:** Встроенный список из 150+ популярных и безопасных сайтов.
- **Удобный менеджер:** Полностью управляемая версия через `manager.exe`.
- **Архивы белого списка:** Экспорт/импорт белого списка в JSON-формате.

---

## 🚀 Быстрый старт

1. **Запустите `manager.exe`** — через это окно вы управляете программой.
2. **Запустите LinkGuard** через менеджер (опция 2).
3. **Копируйте любую ссылку** — программа покажет toast-уведомление о её безопасности.

---

## 📖 Подробная инструкция

### 1. Проверка ссылок

| Тип уведомления | Описание |
|----------------|----------|
| ✅ Зеленое toast | Ссылка безопасна. |
| 🚨 Красное toast | Фишинг обнаружен. |
| 🔴 Красное toast | Сайту меньше 30 дней. |

### 2. Менеджер (`manager.exe`)

| Опция | Действие |
|-------|----------|
| 1 | Добавить домен в белый список |
| 2 | Перезапустить LinkGuard |
| 3 | Выключить LinkGuard |
| 4 | Проверить статус работы |
| 5 | **Удалить программу** (вместе со всеми файлами) |
| 6 | **Удалить только белый список** |
| 7 | **Экспорт белого списка** в `whitelist_archive.json` |
| 8 | **Импорт белого списка** из архива |
| 9 | Выход |
